# M009 design: replace the static discriminating flag (DRAFT, not registered)

Status: design only. Nothing here is frozen or pre-registered. Branch base: `hygiene/frozen-files` (Wilson, decided 2026-09-22, option b — M008 v4 and M007 records untouched; registering M009 supersedes nothing).

## Why M009

- M008 v4 (30/30 runs complete) confirmed both: **K1** 6/8 Haiku Kernel — false cause established from the decoy alone; **K2** 3/8 — the gate approved the wrong fix. New finding beyond the metrics: Sonnet Kernel 0/3 cited decoy+true evidence *together* and still landed wrong — a claim-ranking gap K1 does not capture.
- The mechanism behind both is one line of reality: `discriminating` is a static, author-set boolean the gate blindly trusts (`gate_check`: root_cause at >= inferred citing any `disc=1` artifact, no open contradiction).
- Jev probe arc (2026-09-22, three steps same session): promising n=3 → **reversed** under a harder test (self-disclosed limitation stripped; Jev confidently wrong, conf 0.91–1.00, both scenario families) → **decomposed likelihood-ratio fix validated 4/4** on the stripped, hardest cases. Honest caveat recorded: it only worked because hypothesis B's statement spelled out the shared selection mechanism — the causal completeness lives in the hypothesis writing, not in Jev's reasoning.
- The probe's own conclusion: this needs candidate hypotheses available at **evidence-citation time**, not artifact text alone — a real Kernel design change (rival-hypothesis tracking), not a drop-in API call. Hence a new frozen family, not an M008 patch.

## Question

Does replacing the static flag with mechanism B and/or mechanism C drive the K1/K2 event rate below **X = 25%**, under artifacts that **do not announce their own confound**?

## Mechanisms (Wilson decided 2026-09-22: both, as separate arms)

- **A — control, static flag.** M008's mechanism, unchanged. Concurrent, same artifacts: the only fair baseline, because the new no-self-disclosure artifacts invalidate M008's historical rates as a control.
- **B — Kernel rival-hypothesis tracking.** At citation time the Kernel records what else could explain the same observation; a root_cause whose evidence does not discriminate between recorded rivals cannot satisfy the gate.
- **C — Jev decomposed LR.** Two *separate* Noul calls — P(obs | hypothesis A) and P(obs | hypothesis B), each seeing only one hypothesis — code computes the gap; a threshold decides the flag. Jev never sees both hypotheses together (that is what caused the vocabulary-matching failure).

## Artifacts: hard rule from the probe

M009 artifact texts are M008's mechanism **without any self-disclosed limitation sentence, in any artifact, decoy or true**. A real confound does not announce itself. This rule is why M008's completed results cannot serve as the control: the test got harder. A design review before registration must confirm no artifact states its own limitation (the probe: "avoid re-discovering this same gap after building it").

- rules/raw context arms are **dropped**: M008's completed record already supplies that context; M009's question is mechanism-vs-mechanism in kernel mode. Sonnet C omitted (n=3 buys little for the cost of a third mechanism at Sonnet scale) — either way Sonnet is reported as directional only.
- Final arm table freezes at registration; Wilson approves at prereg review (accept 30, or cut).

## Success bar (Wilson decided 2026-09-22: the proposed X)

- Each intervention arm (B, C): **K1 < 25%** (<= 1/8 Haiku). K2 reported with the same bar, independently.
- **Validity precondition:** the concurrent control arm must be valid — >= 70% of its runs executed the decoy (M008's exposure rule), or the comparison is void and M009 reports that instead.
- Sonnet: directional only, n=3 never meets a rate bar.
