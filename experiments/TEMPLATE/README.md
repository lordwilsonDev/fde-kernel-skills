# Experiment folder template (North Star loop)
Copy to `experiments/<WORLD>/` for the human-readable record; machine records stay in `runs/`.
Files: `charter.md` (question, scope, what would change our mind) - `decision.md` (run / don't run / improve first, thresholds, stop rules, registered BEFORE runs) - `baseline.md` (freeze hashes, prior-family integrity) - `observations.md` (per-run notes, deviations) - `result.md` (arm table, misses, not-verified list).
